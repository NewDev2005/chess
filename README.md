# Chess

## About
The following program is a [capstone project](https://www.theodinproject.com/lessons/ruby-chess) of [ruby course](https://www.theodinproject.com/paths/full-stack-ruby-on-rails/courses/ruby) at [The odin project](https://www.theodinproject.com/dashboard).
This is a command-line chess game build in Ruby without the use of any external library or tool. The chess application has some of  the essential and basic features of the chess.

## Note
This chess application doesn't support any **Draw** conditions right now so if you reach a state like stalemate then you would have to quit the game by entering **exit** 

Also the game doesn't support any feature for **saving** the game state(it is a bit difficult for me to integrate this in my existing codebase).
